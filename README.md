# Portfolio-Optimization-using-Markowitz-Framework
• Implemented mean–variance optimisation to construct the Efficient Frontier and identify Tangency Portfolio (Sharpe
0.47; Return 24.30%; Volatility 38.09%) using 5 Indian equities.
• Enhanced diversification by incorporating NVDA (US equity), improving Sharpe Ratio to 0.67 and reducing volatility
to 33.47%, demonstrating cross-market correlation benefits.
